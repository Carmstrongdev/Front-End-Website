Why Explore California?

California is home to communities with different geographic regions, population sizes, and characteristics. This website provides a simple way to explore selected California cities and compare information about each community.

Use the city pages to learn about the capital and two additional California communities. Each page presents consistent information so the cities can be viewed and compared using the same categories.
